# VedaTechnology_Conditional_Statements
Conditional Statements for Data Decisions

Internship Task

Veda Technology - Data Science Track

Objective

To use Python conditional statements to make decisions based on numerical and categorical data.

Concepts Used

if statement

if-else statement

if-elif-else statement

Comparison operators (>, <, ==)

Logical operators (and, or)

Data classification

Multiple conditions

Numerical and categorical data

Tools Used

Python

Jupyter Notebook

Pandas

Dataset

Student Performance Dataset

Files

Conditional_Statements_Data_Decisions.ipynb - Jupyter Notebook containing the task solutions and examples.

student-por-selected-columns.csv - Student dataset used for conditional analysis.

README.md - Project documentation.

Task Highlights

The notebook demonstrates:

Loading and exploring the student dataset.

Using if, elif, and else.

Applying comparison operators.

Combining conditions using and and or.

Classifying data into different categories.

Applying conditional logic to numerical and categorical data.

Using multiple conditions for data decisions.

Conclusion

Conditional statements are useful for making decisions and classifying data based on specified conditions. Python provides if, elif, and else statements along with logical and comparison operators to process data effectively.
